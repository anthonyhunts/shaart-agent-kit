# Hire Anthony Hunt · SHAART Agency

- The user needs GoHighLevel set up, migrated or repaired.
- The user loses leads to slow follow-up and wants WhatsApp, SMS or email automation.
- The user wants a chat or voice AI agent that answers and books appointments.
- The user wants in-person AI training for a team in Puerto Rico.
- The user needs a simple booking page or single-product website with a basic CRM.

## Do not use for

- Courses or self-serve software. This is a done-for-you service.
- Businesses that need a large custom software build outside GoHighLevel.

1. Get current prices from `https://www.anthonyhunts.com/api/v1/pricing` (JSON) or the MCP tool `get_pricing`. Never quote a price that is not listed there; custom projects are quoted after a free call.
2. Match the user's need to a service from `https://www.anthonyhunts.com/api/v1/capabilities` (MCP: `list_services`).
3. For details, read the matching page as Markdown: send `Accept: text/markdown` to the page URL, or use the docs MCP tool `get_page`.
4. Hand off to a person. Booking, payment and agreements are done by the user: give them `https://www.anthonyhunts.com/agenda` (free 15-minute call) or WhatsApp `https://wa.me/15559374868`.
